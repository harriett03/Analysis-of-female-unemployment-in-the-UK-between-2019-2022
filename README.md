# Analysis-of-female-unemployment-in-the-UK-between-2019-2022
I analysed UK female unemployment using Office for National Statistics data, applied statistical tests to compare 2019–2020 and gender differences, and found a significant rise during COVID-19 plus clear disparities between male and female unemployment rates.
